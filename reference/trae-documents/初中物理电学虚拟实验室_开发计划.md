# 初中物理电学虚拟实验室 — 开发计划

## 1. 概述

面向初中学生与教师，开发一款**离线可运行的网页版电学实验模拟工具**。学生可以像在实验台上一样拖拽元件、用导线连接电路、读取真实计算出的电流/电压、记录数据并填写结论；教师可直接投影演示，或用"示例电路"快速展示标准接法。

产品名：**星火电学实验室（SparkLab · 初中电学）**

### 已确认的需求（来自需求澄清）

| 决策项 | 结论 |
| --- | --- |
| 学科范围 | 首批只做初中物理·电学；首页保留科目选择入口，化学/生物显示"敬请期待"占位 |
| 交付形态 | 纯前端网页，无后端、无网络依赖，可直接双击 `index.html` 在教室电脑/平板离线使用；采用本地存储，后续可平滑接入后端 |
| 首批范围 | 3 个高保真实验 + 可扩展的实验大厅框架 |
| 实验清单 | ① 串并联电路中电流电压的规律 ② 伏安法测电阻 ③ 探究电流与电压、电阻的关系（欧姆定律） |
| 教学方式 | 双模式：引导模式（分步任务 + 自动检测 + 结论填空）与自由探究模式（任意接线 + 实时读数） |
| 数据 | 内置实验记录单，自动累计数据，支持导出 CSV 与打印；不做题库与学情分析 |
| 资源来源 | 允许从 GitHub / 开源素材站下载图标等资源，**下载后本地化**，运行时仍完全离线 |

### 5.1 素材获取与本地化（关键约束）

`file://` 协议下 `fetch()` 读取本地 SVG 会被 CORS 拦截，因此**运行时不能按需加载图标文件**。处理方式：

1. 开发期用 `curl` / `WebFetch` 从 `raw.githubusercontent.com/tabler/tabler-icons/main/icons/outline/<name>.svg` 下载所需 SVG 到 `assets/icons/raw/`，逐个记录来源 URL、版本 tag 与获取日期到 `assets/icons/LICENSE`。
2. 运行 `node tools/build-icons.js` 把所有 SVG 解析为 `{ name: "<path .../>" }` 形式，写入 `assets/icons/sprite.js`（形如 `window.SparkLab.icons = {...}`，classic script）。
3. 运行时通过 `icons.get(name)` 返回内联 SVG 字符串（`currentColor` + `stroke-width:2`，可直接继承 CSS 颜色），插入 DOM。**不产生任何网络请求**。
4. 统一 `viewBox="0 0 24 24"`，通过 CSS 控制尺寸；颜色随主题令牌变化（`--primary` / `--muted` / `--danger`）。

**已核实可用（Tabler Icons, MIT）**

| `circuit-battery` | 电池组元件库图标、引导步骤插画 |

## 6. 核心模块设计

### 6.1 电路数据模型

```js
component = {
  id, type,            // battery | switch | bulb | resistor | rheostat | ammeter | voltmeter
  x, y, rotation,      // 0 / 90 / 180 / 270
  props,               // 各类型专属参数（见下表）
  terminals: [{ id, dx, dy, polarity: '+' | '-' | null }]
}
wire = { id, from: { compId, terminalId }, to: { compId, terminalId } }
```

元件参数：

| 类型 | 参数 | 默认值 / 可选项 |
| --- | --- | --- |
| 电池组 | 节数 1–4（每节 1.5V，内阻 0.5Ω） | 2 节（3V） |
| 开关 | `closed` | 断开 |
| 小灯泡 | 额定 2.5V / 0.3A，R≈8.33Ω | 固定 |
| 定值电阻 | 5 / 10 / 15 / 20 Ω | 10Ω；实验二中作"未知电阻 Rx"，界面上不显示阻值 |
| 滑动变阻器 | 0–20Ω，滑片 `slider∈[0,1]` | 0.5 |
| 电流表 | 量程 0–0.6A / 0–3A，内阻 0.01Ω | 0–0.6A |
| 电压表 | 量程 0–3V / 0–15V，内阻 1MΩ | 0–3V |

### 6.2 求解流程（`circuit.js`）

1. 用并查集把导线连接的端子合并为节点（node）。
2. 生成支路：电阻类（含灯泡、变阻器有效阻值、表内阻）→ 电导戳矩阵；电池 → MNA 电压源行（额外引入内部节点与 0.5Ω/节内阻，保证短路时矩阵不奇异）。
3. 按连通分量分别处理：每个含电源的分量选一个参考节点接地；不含电源的分量电压置 0（对应"未接入"的悬空元件）。
4. 高斯消元（部分主元）求节点电压与支路电流；奇异（数值近零）时放弃该分量并标记 `floating`，不抛异常。
5. 输出：`{ nodeV, branchI, readings, bulbPower, flags }`；一次求解在元件变动时触发（事件驱动，无定时循环）。

**异常检测（教学价值核心）**

- 电源两端等效电阻 < 0.6Ω → `short`：提示"电源短路"，电流表显示超量程，画布高亮短路路径。
- 干路电流为 0 且电路闭合 → `open`：提示"电路断路，请检查导线与开关"。
- 表针反向 → `reverse`：提示"电表正负接线柱接反"。
- 读数超量程 → `overRange`：表针顶死 + 红色提示"超量程，请换大量程"。
- 灯泡 P > 1.5×额定功率 → 灯泡"烧坏"（断路），Toast 提示并可重置。
- 变阻器接法：下+下 → 定值 20Ω；上+上 → 0Ω；只接一侧或未接入 → 提示"请一上一下接线，滑片才能起作用"。

### 6.3 画布交互（`board.js`）

- 元件从左侧元件库**拖入**或**点击添加**到画布（触屏友好），网格 10px 吸附。
- 连线：点击端子（命中区 22px）→ 出现跟随指针的预览导线 → 点击另一端子成线；点空白或 `Esc` 取消；禁止自连同一元件同一端子。
- 导线为三次贝塞尔曲线，选中加粗高亮；删除元件时级联删除其导线；`Delete/Backspace` 删除选中；`R` 旋转 90°。
- 元件可拖动，导线端点实时跟随；"适应窗口"按钮使全部元件居中缩放。
- 空闲时在每条导线上叠加"电流流动"虚线动画（速度 ∝ 电流，方向按电流正负），直观呈现电流方向。

### 6.4 仪表与记录（`meters.js` / `records.js`）

- 表盘：SVG 刻度 + 指针（200ms 平滑旋转）+ 数字二次读数（保留 2 位有效数字，按分度值取整），量程切换为胶囊按钮。
- 记录：每实验定义列结构；点"记录当前数据"追加一行（含时间戳），实验二自动补 `R=U/I` 列并计算平均值。
- CSV：`\uFEFF` BOM + UTF-8，Excel 中文不乱码；文件名 `实验记录_<实验名>_<YYYY-MM-DD>.csv`。
- 打印：`print.css` 仅保留实验名、表头、数据行、结论与日期。
- 存储键：`sparklab:v1:records`、`sparklab:v1:progress`、`sparklab:v1:settings`；损坏数据自动丢弃并重建。

### 6.5 引导模式（`data/experiments.js` + 各 lab 文件）

- 步骤 = `{ title, instruction, hint, check(ctx) }`；每次电路或数据变化后按顺序评估当前步骤的 `check`，满足即自动打勾并进入下一步，右侧显示进度条。
- `check` 是基于图结构的谓词，例如"存在含电源、开关、两只灯泡的闭合回路"、"两灯泡两端节点对相同（并联）"、"电压表跨接在指定元件两端"、"本实验记录行数 ≥3"。
- 结论题为填空（数值容差 5% 或关键词匹配），提交后给对错反馈，"查看参考答案"按钮在提交一次后出现。
- 引导进度持久化，返回大厅显示 `x/y`；"重置"清空当前实验步骤与电路（记录单单独确认）。

### 6.6 音效与动效

- WebAudio 合成、无音频文件：连线"嗒"（440Hz，60ms）、记录确认（660Hz 双音）、警告（220Hz 短音）、步骤完成（上行三音）。
- 音量低（gain≈0.03）、经 1200Hz 低通滤波，符合"轻柔不刺耳"偏好；顶栏可静音并持久化。

## 7. 三个实验的详细规格

### 实验一：串并联电路中电流、电压的规律

- **器材**：电池组、开关、2 只小灯泡、电流表、电压表、导线若干。
- **引导步骤**
  1. 连接串联电路（电源—开关—L1—L2 单回路）。
  2. 闭合开关，观察两灯亮度并记录。
  3. 用电流表分别测量 L1 前、L1 与 L2 之间、L2 后的电流（至少 2 处）。
  4. 用电压表测 L1、L2 两端电压与电源电压。
  5. 改接为并联电路（两灯并列，各有一条支路）。
  6. 测干路电流与两条支路电流。
  7. 测并联时两灯两端电压。
  8. 填写结论：串联 I 相等、U 等于分压之和；并联 I 等于支路电流之和、U 相等。
- **判定要点**：串联识别为"两灯在同一单回路"；并联识别为"存在两条不含彼此的支路并联于同一节点对"；数据行数与数值关系（误差 ≤0.02A / ≤0.1V）。
- **记录表**：实验类型、测点、电流(A)、电压(V)。

### 实验二：伏安法测电阻

- **器材**：电池组（4.5V）、开关、未知定值电阻 Rx（实际 10Ω，界面不显示）、滑动变阻器（0–20Ω）、电流表、电压表。
- **引导步骤**
  1. 按图连接：Rx 与变阻器串联，电流表串联，电压表并联在 Rx 两端，开关控制干路。
  2. 闭合开关前把滑片移到阻值最大端（保护电路）。
  3. 调节滑片，记录 3 组不同的 U、I。
  4. 计算每组 R 与平均值，填写测量结果与误差分析。
- **教学校验**
  - 电压表串联进干路 → 提示"电压表内阻极大，电路几乎没有电流"。
  - 电流表并联在 Rx 两端 → 提示"电流表内阻很小，会造成短路"。
  - 变阻器接成定值（下+下 / 上+上）→ 提示滑片无效。
  - 未把滑片置于最大阻值就闭合 → 提示"闭合前应将滑片移至阻值最大处"。
- **记录表**：组次、电压 U(V)、电流 I(A)、电阻 R(Ω)；底部平均值与偏差。
- **数值预期**：滑片从最大到最小，I 约 0.14–0.43A，R 恒为 10.0Ω（±0.2Ω 读数误差）。

### 实验三：探究电流与电压、电阻的关系

- **器材**：电池组（4.5V）、开关、定值电阻（5/10/15/20Ω 可换）、滑动变阻器、电流表、电压表。
- **引导步骤**
  1. 连接电路（R 与变阻器串联，表计正确接入）。
  2. 固定 R=10Ω，通过滑片改变 R 两端电压，记录 4 组 (U, I)。
  3. 生成 I–U 散点图与拟合直线，观察正比关系。
  4. 保持 R 两端电压为 2V，依次更换 5/10/15/20Ω，记录 4 组 (R, I)。
  5. 生成 I–1/R 关系，归纳 I=U/R。
- **图表**：SVG 坐标系 + 散点 + 最小二乘拟合线，坐标轴自动取整刻度；切换电阻时自动清空不匹配数据提示。
- **记录表**：组次、R(Ω)、U(V)、I(A)、U/I(Ω)。

## 8. 视觉与体验规范

- 设计令牌：`--bg:#f5f7fb`、`--panel:#fff`、`--ink:#16233a`、`--muted:#5b6b82`、`--primary:#1f6fb2`、`--accent:#f2994a`、`--danger:#e05252`、`--ok:#2fa36b`、`--line:#dfe6f0`；圆角 16px，阴影 `0 8px 24px rgba(22,35,58,.08)`。
- 字体：系统字体栈（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`），不加载外部字体。
- 元件采用统一扁平矢量风格（深灰描边 + 浅色填充），端子为正负色标；灯泡发光用径向渐变，亮度 ∝ P/额定功率。
- 交互尺寸：按钮高 ≥44px，端子命中区 22px，表格行高 ≥40px；焦点环可见；读数与警告用 `aria-live="polite"`。
- 响应式断点：1180 / 1100 / 760；平板横屏为主要目标场景。
- 空状态：无记录时显示"还没有数据，接线后点击『记录当前数据』"。

## 9. 假设与决策（已定，不再询问）

1. 免费电池组最多 4 节、内阻 0.5Ω/节——用于让短路有真实但有限的电流，同时不破坏串并联电压规律。
2. 灯泡按线性电阻处理（8.33Ω），不做灯丝温度曲线，保证初中数据可解释。
3. "烧坏"阈值设为 1.5 倍额定功率，且可一键重置，避免课堂卡死。
4. 引导模式允许使用"载入示例电路"，便于教师课堂演示；步骤仍需满足检测条件。
5. 记录与进度只存本机浏览器，不做账号、不做上传、不做班级管理（后续接后端时再扩展）。
6. 化学/生物只做入口占位与"敬请期待"提示，不写任何伪内容。
7. 首页不做登录/隐藏后台入口——本项目无管理端。
8. 图标只从 Tabler Icons（MIT）下载界面与元件图标；滑动变阻器、单刀开关因上游无对应图标而自绘教材标准画法。所有素材本地化后随项目分发，并在 `assets/icons/LICENSE` 注明来源与许可。
9. Node 仅在开发期用于 `tools/build-icons.js` 与 `tests/circuit.test.js`；最终交付物不需要 Node 环境。
